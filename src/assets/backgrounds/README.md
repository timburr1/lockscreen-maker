Drop background images here (jpg, jpeg, png, webp). Any filename works; every image in this folder is picked up automatically at build time.

Credits go in `credits.json` in this folder, keyed by file name: `{ "file.jpg": { "credit": "Name", "license": "CC BY 2.0", "sourceUrl": "https://..." } }`. `sourceUrl` is optional. Images without an entry are not credited.
